## Features  
NISLOG allows you to change the display format by adding a `type=` query parameter to the URL. For example, using `?type=treemap` will switch to a treemap view.

Supported display types:
- `type=treemap`  
  Treemap view  
- `type=heatmap`  
  Heatmap view  
- `type=bars`  
  Bar chart view
